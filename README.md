# Shatter Me: Interactive World

A first-person, 3D exploration experience inspired by the world and atmosphere of Tahereh Mafi's Shatter Me series.

## Features
- First-person movement and camera controls
- Interactive lore-rich locations
- NPC dialogue encounters
- Atmospheric lighting, fog, and glowing landmarks
- Inspired by the emotional tone and political structure of the novels

## Install
```bash
python -m venv .venv
source .venv/bin/activate
pip install ursina
```

## Run
```bash
python main.py
```

## Controls
- WASD: Move
- Mouse: Look around
- Space: Jump
- E: Interact with a location or NPC
- ESC: Unlock the cursor

## Notes
This project is a book-inspired interactive prototype, not a literal recreation of the novels' events. It focuses on the emotional atmosphere, major themes, and iconic locations of the world.
